Image + MP3 Batch Video Maker

Ye app same naam wali image aur audio file ko pair karke individual MP4 video banata hai.

Example:

Image:
Dil Mera Ronda.jpg

Audio:
Dil Mera Ronda.mp3

Output:
Dil Mera Ronda.mp4

Run Command:

streamlit run app.py

Requirement:
System me FFmpeg installed hona chahiye.

key : 
python -m streamlit run app.py
